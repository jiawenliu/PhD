\begin{abstractpage}
    Program analysis analyzes the behaviors of a computer program, such as resource usage, where people analyze whether a piece of code consumes certain resources and how much specific resources are used by a program / certain pieces of code.
    In this data dependency property, people analyze whether certain data is dependent on others and how many times certain data are dependent during multiple executions.
    People also analyze its safety property, where we care if a certain program/ code leaks a secret and how it leaks such secrets. They all share the same two sub-properties, "How Much" and "Whether," from two perspectives.
    We refer to the two perspectives as \emph{quantitative} and \emph{reachability}, and we name this class of properties as \emph{quantitative-reachability} property. Existing analysis from one perspective is not precise enough to capture these properties. For example, reachability analysis only tells us whether the output relies on user input, whether the confidential data is leaked, whether some code is executed, etc., but not how many times or how long these properties hold for programs. 
    Quantitative analysis, such as program complexity and cost analysis, only tells us the upper bound on the overall worst-case quantity but not where the resource is cost, where the data is leaked, etc.
    This thesis presents algorithms that complement two lines of techniques effectively and shows their effectiveness in analyzing two representative quantitative-reachability properties by controlling the program's execution behavior in higher granularity. 
    
    The first noteworthy property we look into is the adaptivity rounds of the programs in adaptive data analysis, which is composed of multiple queries by data analysts.
    Among these queries, the choice of some may depend on previous queries' results, and they form dependent relations with each other. Adaptivity is intuitively the depth of the chain of dependent queries during these dependence relations. Reasoning about adaptivity is useful in controlling the generalization error of adaptive data analysis, which usually propagates sharply along with the dependency chain. Researchers in the data analysis area have found that the generalization error can be controlled well by choosing the appropriate statistic technique according to the adaptivity. Nevertheless, adaptivity is not always clear to data analysts when they need it. To solve this dilemma, we present a program analysis algorithm based on dependency graphs to provide an upper bound on adaptivity to assist data analysts. We first define the adaptivity in a formal semantics model and then design a program analysis framework combining the dependency analysis and quantitative analysis techniques for statistically estimating the adaptivity. 

    As a continuation of the previous problem, to get a more precise bound on the adaptivity, we look at the second quantitative-reachability property – the number of times a given control location inside a procedure is visited during the program execution. The upper bound on this execution number for a given control location is referred to as the \emph{reachability-bound} by~\cite{GulwaniZ10} in the first place. A tight reachability-bound can help to improve the analysis result on other program features such as the resource cost, the adaptivity of data analysis programs, the information leakage in the security analysis area, etc. Though many program analysis algorithms estimate the program's loop bound or overall complexity, there is not a general analysis algorithm that solves reachability-bound for each program location directly or path-sensitively. Moreover, computing a tight reachability-bound for a given program control location is challenging. To leverage these limitations, we present a path-sensitive reachability-bound algorithm to find a precise symbolic reachability-bound on the program's every control location. Our algorithm brings together two techniques: 1. the ranking function based amortized bound analysis through program abstraction, and 2. the loop summarization based multiple loop paths refinement, and combines them effectively. The effective combination improves the precision of the estimated reachability-bound compared to applying either. We implement a prototype and report on an experimental comparison with state-of-art tools over four different benchmarks.
\end{abstractpage}
