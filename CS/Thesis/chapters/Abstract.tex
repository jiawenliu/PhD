\begin{abstractpage}
    Program analysis analyzes the behaviors of a computer program, such as resource usage, where people analyze whether a piece of code consumes certain resources and how much specific resources are used by a program / certain pieces of code.
    People also analyze its safety behavior, where we care if a certain program / code leaks a secret and how much secret it leaks. 
    In terms of the privacy behavior, people analyze whether certain private data is dependent on others and how many times they are dependent during multiple executions.
    Analyzing these behaviors are all focusing on analyzing the same two sub-properties, "How Much" and "Whether" from two perspectives.
    We refer to the two perspective sub-properties as \emph{quantitative} and \emph{reachability} properties, and we refer to this class of behaviors as a hyper-property named \emph{quantitative-reachability} property.
    Existing analysis that are mainly from one perspective is not precise enough to capture these properties.
    For example, reachability analysis only tells us whether the output relies on user input, whether the confidential data is leaked, whether some code is executed, etc., but not how many times or how long these properties hold for programs. 
    Quantitative analysis, such as program complexity and cost analysis, only tells us the upper bound on the overall worst-case quantity but not where the resource is cost, where the data is leaked, etc.
    This thesis presents algorithms that complement two lines of analysis and shows the effectiveness in analyzing two representative quantitative-reachability properties by controlling the program's execution behavior in a higher granularity. 
    
    The first noteworthy property we look into is the adaptivity rounds of the programs in adaptive data analysis, which is composed of multiple queries by data analysts.
    Among these queries, the choice of some queries may depend on previous queries' results, and they form dependent relations with each other.
    Adaptivity is intuitively the depth of the chain of dependent queries during these dependence relations.
    Reasoning about adaptivity is useful in controlling the generalization error of adaptive data analysis, which usually propagates sharply along with the dependency chain.
    Researchers in the data analysis area have found that the generalization error can be controlled well by choosing the appropriate statistic technique according to the adaptivity.
    Nevertheless, adaptivity is not always clear to data analysts when they need it. To solve this dilemma, we present a program analysis algorithm based on dependency graphs to provide an upper bound on adaptivity to assist data analysts. 
    We first define the adaptivity in a formal semantics model and then design a program analysis framework combining the dependency analysis and quantitative analysis techniques for statistically estimating the adaptivity. 

    As a continuation of the previous problem, to get a more precise bound on the adaptivity, we look at the second quantitative-reachability property – the number of times a given control location inside a procedure is visited during the program execution.
    The upper bound on this property is referred to as the \emph{reachability-bound} by~\cite{GulwaniZ10} in the first place. 
    A tight reachability-bound can help to improve the analysis results on other program features beyond itself,
    such as the resource cost, the adaptivity of data analysis programs, the information leakage in the security analysis area, etc. 
    Though many program analysis algorithms estimate the program's loop bound or overall complexity, there is not a general analysis algorithm that solves reachability-bound for each program location directly or path-sensitively. 
    We present a path-sensitive reachability-bound algorithm.
    In comparison with previous works, our algorithm is the first one to exploit path-sensitivity to compute precise reachability-bounds for every program location.
    By doing this, we bring together two techniques from resource analysis: 1. amortized bound analysis through program abstraction and ranking function estimation, and 2. summarization-based multiple loop paths refinement.
    Building on this combination, we focus on two new quantities, \emph{path reachability-bound} and \emph{loop reachability-bound}, which allow us to leverage the precision and efficiency of the two techniques, and allow us to compute precise reachability-bounds for each program point in a path-sensitive way.
    We implemented our algorithm in a prototype, and we report on an experimental comparison with state-of-art tools over four different sets of benchmarks.
\end{abstractpage}
