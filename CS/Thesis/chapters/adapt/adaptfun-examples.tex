\paragraph{Example II.}
The example program from Figure~\ref{fig:abscfg_loopQuery}(a) has similar estimated dependency graph
as the $\kw{twoRounds}$ example.
In the same way, we find its longest walk as $l^6 \to a^5 \to y^3 \to x^0$.
Different from the $\kw{twoRounds}$ example, there is a dependency relation from the first query
request, $\clabel{\assign{x}{\query(\chi[0])}}^0 $ to the commands inside the loop body passing through control flow.
In this sense, it has adaptivity $3$, and we find its longest walk as $l^6 \to a^5 \to y^3 \to x^0$.
The query length of this walk is $3$ given that only the three vertices  $l^6, y^3$ and $x^0$
correspond to query requests.
