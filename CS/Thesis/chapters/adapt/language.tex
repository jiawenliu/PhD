In this part, 
we introduce the program language model for implementing the data analyses.  
This is an extended standard while language with primitives for query requests.
% It improves the expressiveness of previous language design for adaptivity analysis in a large scale.
We first give the syntax of the language in Section~\ref{sec:language-syntax} with
explanation on the novelty of this language.
Section~\ref{sec:language-os} contains the trace-based operational semantics. 
This is the main technical ingredient to define the program's adaptivity formally.
Section~\ref{sec:language-examples} in the last part presents an example manually demonstrating the language and the operational semantics
rules.
