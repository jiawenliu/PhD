There are two main parts of the work in this thesis.
The first part focus on formalizing and analyzing the \emph{adaptivity} -- a quantity property -- for the programs in data analysis area,
through the static program analysis techniques.
The second part focus on solving the Reachability-bound Problem through by program analysis techniques as well.
\begin{enumerate}

    \item \redd{PART \romannum{2} \quad  PROGRAM ANALYSIS FRAMEWORK FOR ADAPTIVE DATA ANALYSIS}
    shows the work on the program analysis algorithms to study the adaptivity of the adaptive data analysis program.    

    \paragraph{Chapter~\ref{sec:adapt-intro}} gives the introduction of adaptive data analysis in Section~\ref{sec:adapt-background} and the challenges (Section~\ref{sec:adapt-motivation}) we face to obtain the adaptivity to control the generalization error of an adaptive data analysis program, with an outline of this part in Section~\ref{sec:adapt-outline}.
    
    \paragraph{Chapter~\ref{sec:prework}} introduces the previous works on adaptivity analysis.
    It contains a short summary of the language designs in Section~\ref{sec:prework-language} 
    the adaptivity formalization through program analysis over the trace-based operational semantics (Section~\ref{sec:prework-formalization}),
    and previous program analysis algorithm that is used to estimate the adaptivity of the data analysis programs 
    in Section~\ref{sec:prework-static}
    Their algorithm first introduces the SSA version of the loop language
    to enable an easier analysis over adaptivity by an easier tracking of dependency relations between variables based of the limitation of direct analysis over the loop language
    Following with a three-step algorithm, which constructs a data control dependency graph, and add weights to the graph. The adaptivity is estimated by the weight of the path with the highest weight.


    \paragraph*{Chapter~\ref{sec:adapt-analysis}} presents the new adaptivity analysis framework with significant improvement in three sections.
    
    Section~\ref{sec:adapt-language} present an expressive while-like language. This extended language supports more general adadptive data analysis.
    
    Section~\ref{sec:adapt-exe} presents the new definition for
    the intuitive \emph{adaptivity} rounds for a given data analysis program through a formal semantics model.
    It is defined in three steps. 
%
    The Section~\ref{sec:dynamic-datadep} reasons the \emph{data-dependency} between every query, 
    through the methodology of semantic data dependency analysis.
%
    In Section~\ref{sec:dynamic-graph}, it analyzes the \emph{dependency-quantity} 
    based on the \emph{data-dependency} above.
    Then combines quantitative information with dependency information, it construct a weighted dependency graph,
    the \emph{semantics-based dependency graph}.
    %
    Then in Section~\ref{sec:dynamic-adapt} define the formal \emph{adaptivity} model in definition~\ref{def:trace_adapt} as a quantitative reachability property.
   Based on the \emph{semantics-based dependency graph} and combines both \emph{data-dependency} and \emph{dependency-quantity} property.

    Section~\ref{sec:adapt-static} develops a static program adaptivity analysis framework, named {\THESYSTEM}.
    This analysis combines both data dependency analysis with resource cost analysis techniques.
    It is developed in as follows in order to accurately approximate the formal \emph{adaptivity} definition
    through static program analysis techniques. 

    In Section~\ref{sec:alg_vertexgen},~\ref{sec:alg_weightedgegen} and~\ref{sec:alg_graphgen}, it constructs the 
    \emph{estimate dependence} graph for approximating the \emph{semantics-based dependency graph}.
    Specifically, in Section~\ref{sec:alg_edgegen}, it first represents a combined data-control flow analysis algorithm estimating the data \emph{data-dependency} relation and estimates the edge of this graph.
    In Section~\ref{sec:alg_weightgen} presents a reachability-bound analysis algorithm. It estimates the \emph{dependency-quantity} information of \emph{adaptivity}, specifically the weight of this graph.
    Then Section~\ref{sec:alg_graphgen} combines all information and constructs the 
    \emph{estimate dependence} graph.
    The Section~\ref{sec:alg_adaptcompute} presents an efficient and accurate path search algorithm. It computes the \emph{adaptive} from the estimated graph.
    % , specifically estimating     

    \paragraph{Chapter~\ref{sec:adapt-implementation}} presents five manual examples demonstrating this framework in Section~\ref{sec:adapt-example},
    and the experimental results on some real world data analysis algorithms in Section~\ref{sec:adapt-eval}.
    
    \paragraph{Chapter~\ref{sec:adapt-relatedwork}} discusses the related works from three perspectives:
    the semantics based dependency  analysis and formalization(Section~\ref{sec:relatedwork-adapt-semantics}), the static program analysis (Section~\ref{sec:relatedwork-adapt-static}), and the works about generalization error in adaptive data analysis (Section~\ref{sec:relatedwork-adapt-error}).  

    \item \redd{PART \romannum{1} \quad  REACHABILITY BOUND ANALYSIS}

    \paragraph{Chapter~\ref{sec:reachability-intro}} first gives the introduction of the
    \emph{Reachability-bound} Problem in
    Section~\ref{sec:reachability-background}.
    Then it presents the motivation and existing limitations on this problem and give the overview of the new algorithm in
    Section~\ref{sec:reachability-motivation}.
    In Section~\ref{sec:reachability-outline}, it presents the structure of this chapter.

    \paragraph{Chapter~\ref{sec:reachability-analysis}} presents the {Path-sensitive Reachability Bound analysis} in following sections.
    In Section~{\ref{sec:psRB-language}} first give the language and program model formally, including the
    language syntax in Section~\ref{sec:psRB-language-syntax} and the trace-based operational semantics in Section~\ref{sec:psRB-language-semantics}.
    
    Section~\ref{sec:psRB-definition} gives the \emph{Reachability-bound} definition.

    Section~\ref{sec:psRB-analysis-alg} presents the new \emph{Path-sensitive reachability-bound} analysis algorithm, named $\kw{psRB}$ through following subsections.
    %
    Section~\ref{sec:psRB-preface} first gives the main steps of this algorithm as a structural section. There are five steps in this algorithm.
    In Section~\ref{sec:psRB-progabs}, the first step abstracted the program into an \emph{abstract transition graph}.
    Based on this graph, Section~\ref{sec:psRB-refine} then refines the multi-paths loop in this program and generates a refined program.
    According to the graph and the refined program, Section~\ref{sec:psRB-rank} computes the ranking function for each edge on the graph and estimates the value of each ranking function.
    \subsection{Loop Bound and Path Local Reachability-bound Computation}
    Section~\ref{sec:psRB-pathlocalrb} and \ref{sec:psRB-looprb} then computes the \emph{loop reachability-bound} and \emph{loop reachability-bound} for each path and loop of this program using the ranking function and the graph.
    Then Section~\ref{sec:psRB-rb} finally gives the \emph{path-sensitive reachability-bound} computation algorithm for each program point.

    \paragraph{Chapter~{\ref{sec:psRB-eval}}} first represents ste-by-step examples to illustrate the algorithm clearly in Section~\ref{sec:psRB-example},
    and the implementation and evaluation results on over some real world benchmarks in Section~\ref{sec:psRB-eval}.
    
    \paragraph{Chapter~\ref{sec:psrB-relatedwork}} discusses the related works in this area.
