In comparison to those related works, this dissertation has the following contributions.

\begin{itemize}
 \item 
 In \redd{PART \romannum{1}}, I present a programming language framework for adaptive data analyses where programs represent analysts that can query generalization-preserving mechanisms mediating the access to some data. 
 
 Based on this language framework, I give a formal definition of the intuitive notation -- adaptivity -- under the analyst-mechanism model.
 The new formalization methodology considers both the \emph{reachability} and the \emph{quantitative} sub-properties of this \emph{adaptivity} program property.
 % \emph{quantitative-reachability} property
 % \item 

 Then we design a static program analysis algorithm {\THESYSTEM}
 to estimate the \emph{adaptivity} of a program. This new analysis method estimates
 both the \emph{reachability} and the \emph{quantitative} sub-properties and computes the \emph{adaptivity} of a program accurately.
 We also provide a soundness proof of the program analysis showing that the adaptivity estimated by {\THESYSTEM} bounds the \emph{adaptivity} of the program given by the formal definition. 
 
 We also implement this algorithm and report the empirical evaluation results on several examples.
 % \item An implementation of {\THESYSTEM} and an experimental evaluation of the bounds this implementation provides on several examples.

 Designing of this framework is jointly done with Marco Gaboardi, Deepak Garg, Jonathan Ullman and Weihao Qu, and the empirical evaluation is jointly finished with Weihao Qu.
 
 \item In \redd{PART \romannum{2}}, I propose
 a path-sensitive reachability-bound algorithm, which computes sound bound on the evaluation times of each program point path-sensitively. This algorithm integrates the path refinement approach into the \emph{amortized bound analysis} through ranking function estimation.
 We introduce two novel quantities in this algorithm, the \emph{path reachability-bound} and \emph{loop reachability-bound}, and the corresponding estimating algorithms.
 
 Then I implement this algorithm as a prototype and present the evaluation results over four different benchmarks.
 
 Results of this part is done by myself with the help of writing from Marco Gaboardi.

\end{itemize}
