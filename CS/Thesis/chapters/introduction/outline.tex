There are two main parts of the work in this thesis.
The first part focus on formalizing and analyzing the \emph{adaptivity} -- a quantitative reachability property -- for the programs in data analysis area,
through semantics-based formalization and the static program analysis techniques.
The second part focus on computing the precise reachability-bound for every program control point.
