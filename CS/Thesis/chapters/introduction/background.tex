When a data analysis algorithm is adaptive where the choice of the next query may rely on the results of previous queries, the error in each query can propagate through
the dependency chain and brings high generalization error. 
In light of existing machine learning studies, some researchers found that 
determining the appropriate statistical technique based on the length of this dependency chain, namely the \emph{adaptivity} level can help in controlling 
the generalization error.
In this sense, we are interested in studying this intuitive notion -- the \emph{adaptivity} level
by using the principles of programming languages in \redd{PART \romannum{1}}
to help to reduce the generalization error of the data analysis programs.
% \\
Specifically, we consider that the data analyses are implemented in a \emph{while}-like language and formalize this intuitive notion -- the \emph{adaptivity} level as a program \emph{quantitative-reachability} property.
This \emph{adaptivity} property captures the generalization error in terms of whether the query asked by a program is dependent on each other (the \emph{reachability} sub-property of \emph{adaptivity}) and how many times they are dependent (the \emph{quantitative} sub-property of \emph{adaptivity}).
By analyzing the \emph{adaptivity} and helping the data analyst to reduce the generalization error,

improve the user's experience with respect to \emph{convenience} and \emph{enjoyment}.

These two properties can be captured as two sub-properties by a \emph{quantitative-reachability} hyper-property

In~\cite{GulwaniJK09}, an upper bound on this property is referred to as the \emph{reachability-bound}. Specifically, it is a worst-case upper bound on the number of times a given program location 
inside a procedure is visited during the program execution.
The \emph{reachability-bound} on each program location has broad applications in analyzing other program properties beyond itself.
For example, in the resource cost analysis area, 
it
% this \emph{quantitative-reachability} property

bound on a program's resources consumption,
such as time consumption, memory consumption,

In the data analysis area, when we analyze a program's \emph{adaptivity}
as discussed above,
an accurate \emph{reachability-bound} on each program location
can improve the precision of the \emph{adaptivity} analysis result.
In this sense, analyzing and controlling the \emph{reachability-bound} can help to improve programs reliability, security, privacy, usability, etc., and then bring the
\emph{efficiency} and \emph{privacy} to people when they use these programs.
