Program analysis has a long history to analyze and control the program's execution behavior.
Since a few decades ago, when computer programs were only used for research or business purpose and the expectation of computer programs was just to execute correctly without bugs,
the most critical behavior with respect to programs is the execution correctness behavior.
In this sense, the program analysis community pays much attention to analyzing functional correctness properties.
It determines whether a program executes correctly without getting stuck because of bugs.

However, the expectation has also changed along with the popularity of mobile devices and the wide applications of big data. 
It is not enough for these programs running on mobile phones or those programs handling big data, 
to just run without bugs. 
The non-functional execution properties come into play in the new era.
We think programs on mobile devices are of great significance in today's life.
To provide people with high-quality mobile devices

\emph{enjoyment}, and the \emph{efficiency}.

In light of existing machine learning studies, some researchers found that certain non-functional properties of data analysis algorithms can help to control the generalization error, especially when the data analysis is adaptive.
\\
We notice one of these non-functional properties that is critical in controlling the generalization error can be expressed from two perspectives, the \emph{quantitative} and \emph{reachability}.
This property captures the generalization error in terms of whether the sample data that is queried by the algorithm are dependent on each other (the \emph{reachability}) and how many times they are dependent (the \emph{quantitative}).
We are interested in analyzing it as a \emph{quantitative-reachability} property using the principles of programming languages to help reduce the generalization error of the corresponding algorithm.
In this sense, we can help to improve the accuracy for the recommendation results computed by these algorithms

To study the two conceptual \emph{quantitative-reachability} properties from the principles of programming language, we first formalize them through specific programming language models.
Then we develop new static program analysis frameworks to best exploit the benefit of these properties in different areas.
However, to fully utilize the aforementioned benefits of the new analysis frameworks on these non-functional properties, the appropriate implementation is inevitable. 
To this end, we also take one step in algorithmizing and implementing the analysis frameworks
which is used to formalize and statically estimate these properties.
The evaluation results over real-world benchmarks report the effectiveness of our work in the real world and its potential applications beyond the program analysis area.
