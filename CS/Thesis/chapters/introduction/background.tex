When a data analysis algorithm is adaptive where the choice of which query to run next may rely on the results of previous queries, the error in each query can propagate through
the dependency chain and brings to high generalization error. 
In light of existing machine learning studies, some researchers found that 
determining the appropriate statistical technique based on the length of this  dependency chain can help in controlling 
the generalization error.
In this sense, we are interested in studying the length of this dependency chain in an adaptive data analysis strategy, intuitively the \emph{adaptivity} level using the principles of programming languages to help reduce the generalization error.
Specifically, we consider the data analyses are implemented in a while-like language and formalize this intuitive notion  \emph{adaptivity} as a \emph{quantitative-reachability} property of the programs that implement certain data analyses.
